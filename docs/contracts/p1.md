```json
{
  "id": "obs-7de9f63c97f5",
  "source": "prometheus.query",
  "query": "sum(rate(http_requests_total{code=~\"5..\"}[30m]))",
  "window": null,
  "summary": "查询完成（http_5xx_rate）：共 1 条序列…",
  "status": "ok",
  "data": [ {"metric": {"job": "makejob-gateway-http"}, "value": [1788607344, "0.42"]} ],
  "created_at": "2026-09-05T15:35:20Z"
}
```
- 404 `{"error": "..."}`：工单或观察不存在
- `data` 为原始 JSON（Prometheus vector/matrix 或 K8s 结构），前端 EvidenceDrawer 直接展示
